**How to apply:** reuse these when writing E04 package.json; re-verify dates if revisited later (registry is authoritative, this snapshot decays).

## Decisive constraints found (the non-obvious ones)
- **Vite 6.0.0–6.4.1 are VULNERABLE**: GHSA-p9ff-h696-f583 (dev-server WS arbitrary file read) + GHSA-4w7w-66w2-5vf9 (path traversal in optimized-deps .map). BOTH fixed in **vite 6.4.2**. Min safe Vite 6 = 6.4.2.
- **@vitejs/plugin-react 6.x requires vite ^8.0.0 (hard peer)**. To stay on Vite 6 you MUST use plugin-react **5.2.0** (peer: vite ^4.2|^5|^6|^7|^8). plugin-react 6.x is the Vite-8-only line.
- **eslint-plugin-jsx-a11y 6.10.2 does NOT support ESLint 10** (peer caps at ^9; official v10 support was unmerged PRs as of Feb 2026). This forces **ESLint 9.x** for a clean tree. ESLint 10 would need the `eslint-plugin-jsx-a11y-x` fork or a peer override.
- **vitest 4.x peer/dep on vite = ^6 || ^7 || ^8** → vitest 4.1.7 works with vite 6.4.2. coverage-v8 peer pins EXACTLY to the vitest version (must equal vitest).
- **typescript-eslint 8.59.4 peer typescript = >=4.8.4 <6.1.0** → TS 6.0.3 IS supported.
- **@testing-library/react 16.3.2** peer react ^18||^19 → React 19 OK.
- **@types/react-dom latest = 19.2.3** (2025-11-12) — no newer 19.2.x exists; pairs fine with @types/react 19.2.15.
